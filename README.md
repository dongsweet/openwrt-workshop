# luci-app-v2ray-adv

这是一个面向 OpenWrt 的高阶 V2Ray LuCI 配置界面（luci-app-v2ray-adv），提供细致入微的 V2Ray 节点配置以及透明代理（TProxy）等进阶路由功能，通过 iptables 和 rpfilter 等实现精细化网络流量接管。

## 功能特性

*   **多节点管理与一键切换**：支持添加多个不同协议（VMess/VLESS/Trojan 等）类型的 V2Ray 节点，并可一键切换主用节点。
*   **透明代理（TProxy）支持**：支持局域网设备的透明代理接入，支持 UDP 转发。
*   **黑白名单分流**：根据 GFW 列表或大陆 IP（CN IPSet）进行自动化的按需分流，减少非必须的代理消耗。
*   **端口范围自定义**：允许用户自定义需要透明代理接管的目标端口范围，默认代理 80 及 443 等常用端口。
*   **日志和运行状态查看**：内建系统服务状态查看和客户端运行日志读取，方便诊断排错。
*   **服务探测机制**：支持自动探测 V2Ray 核心程序的路径。

## 编译及安装说明

请参考 OpenWrt 官方 LuCI App 编译及开发指南进行编译（可放置于 `package/` 目录中随系统一同编译），或者直接通过相关 CI/CD 流程构建 `.ipk` 安装包，在 OpenWrt 系统上使用 `opkg` 进行安装。
